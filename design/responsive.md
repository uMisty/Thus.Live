# 响应式约定

| 宽度 | 布局 |
| --- | --- |
| 桌面 | 1120px 站点容器，960px 列表，760px 正文及右侧粘性目录 |
| ≤1100px | 缩小外边距和目录间距 |
| ≤860px | 单栏正文；目录放在文章开头，可展开 |
| ≤560px | 两行导航；时间轴月份放在日期上方，左侧保留连线 |
| 所有宽度 | 多标签自动换行；代码、公式、表格在自身区域横向滚动 |

作者信息与日期、阅读时长位于同一信息行，空间不足时自然换行。搜索弹窗使用原生 dialog 的焦点管理。支持键盘导航和减少动画设置。

浏览器测试覆盖 320、390、768、1440px。截图脚本见 `scripts/capture-preview.mjs`。
